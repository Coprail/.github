# Coprail

The guardrails for AI agents.

Coprail is the control layer for AI-assisted software development. It lets coding agents work inside boundaries that developers and organizations define, enforce, and audit.

## Repositories

- [plan](https://github.com/Coprail/plan) — product specifications (private)
- [coprail](https://github.com/Coprail/coprail) — local engine, daemon, CLI, and Cursor shim (private until the CLI candidate)

A Homebrew tap, a public website, and an organisation control plane come later. Those repositories are not created yet.
